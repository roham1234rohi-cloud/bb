BREACH REPORT - راهنمای انتشار روی Netlify

ساختار پوشه:
  index.html
  css/style.css
  js/main.js
  assets/favicon.svg

مراحل:
1. فایل ZIP را Extract کنید تا پوشهٔ breach-report-site ساخته شود.
2. وارد netlify.com شوید و Sign in کنید.
3. در بخش Sites گزینهٔ Add new site > Deploy manually را بزنید
   (نام دقیق گزینه‌ها ممکن است تغییر کند).
4. خود پوشهٔ breach-report-site را (نه فایل ZIP) داخل کادر Drag & Drop بکشید.
5. آدرس ساخته‌شده را باز کنید و لینک‌ها و ظاهر موبایل را تست کنید.

نام زیردامنه را می‌توانید در Site configuration > Change site name تغییر دهید (اگر آزاد باشد).
دامنهٔ اختصاصی اختیاری است و ممکن است هزینه داشته باشد.

تصویر اشتراک‌گذاری (OG): یک تصویر واقعی 1200x630 داخل assets بگذارید و
تگ og:image را طبق کامنت داخل index.html اضافه کنید.
